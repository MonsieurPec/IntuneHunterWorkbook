# Security

This workbook surfaces sensitive audit data (LAPS recovery requests, PIM role
activations, UPNs) once imported into a tenant — see the RBAC note in
[02-requirements.md](02-requirements.md). Vulnerabilities in this repository itself
(for example, a query or documentation change that would widen that exposure
beyond what's already documented) can be reported privately through this
repository's **Security > Report a vulnerability** tab (GitHub Security
Advisories), rather than as a public issue.

This is a personal project maintained on a best-effort basis — see
[08-contributing.md](08-contributing.md).
